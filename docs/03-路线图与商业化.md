# 03 · 路线图与商业化

---

## 一、产品路线图

排序原则：**先给「不用 AI 也离不开」的地基（数据沉淀 + 送达率），再叠加 AI 增长能力**。理由——如果第一版就主打 AI 获客，客户会用「线索质量」这一个指标来评判你，而线索质量高度依赖数据源和调优，容易开局即失败；先做 CRM 与收件箱，客户的数据沉淀进来，切换成本立刻建立。

### M0 · 地基（0–3 个月）— 目标：10 家种子客户，可日常使用

| 交付 | 说明 |
|---|---|
| 客户数据中台 | Company/Contact 主数据、去重合并、全域时间线 |
| 公海/私海机制 | 容量上限、自动回收、离职一键交接 |
| 统一收件箱（邮件） | IMAP/OAuth 接入、AI 摘要、意向打标、SLA 首响时钟 |
| 商机看板 + 报价/PI | 版本化报价、成本与汇率快照、PI 生成（多语言） |
| 送达率基建 | SPF/DKIM/DMARC 体检、发信域健康分、预热与限速 |
| 合规基线 | 页脚注入、全局退订中心、审计日志 |
| 双角色工作台 | 业务员 / 老板两套信息架构 |

**M0 成功判据**：种子客户 DAU/席位 > 60%，且愿意把主邮箱接进来（这是信任的真实检验）。

### M1 · 获客与自动化（3–6 个月）— 目标：50 家付费客户

- 线索雷达：海关数据 + Google 搜索 + Maps + 展会名录接入，AI 四维评分
- 联系人补全（decision-maker enrichment）
- 多渠道序列编排 + A/B 测试
- WhatsApp Business Cloud API 接入 + opt-in 证据链
- AI 回复草稿（基于产品库与历史成交）
- 渠道 ROI 归因看板 v1

### M2 · 内容与站群（6–9 个月）— 目标：ARR 500 万

- 内容工厂：选题雷达 → 多语言成文 → GEO 结构化输出
- AI 建站 + 站群管理（母子站、hreflang/canonical、Git 部署 + CDN）
- SEO/GEO 体检与 AI 引用监测
- 官网访客识别 → 线索回流闭环

### M3 · 交付与编排平台（9–15 个月）— 目标：ARR 2000 万，进入 L3 客户

- 订单交付：节点甘特、单证清单、跨部门任务签收、客户进度自动通报
- 收款与账龄、汇率损益
- Agent 编排平台开放：自定义 Agent、目标/计划/任务、L0–L3 自主级别、运行回放
- MCP 工具开放，客户可接入自有 ERP/PLM
- 开放 API + Webhook + 应用市场雏形

### M4 · 生态与规模化（15 个月 +）

- 行业模板包（机械/汽配/家居/五金/纺织…）：预置产品结构、话术库、内容选题库
- 服务商生态（代运营、建站、翻译）
- 数据产品：脱敏行业基准（「你的 PI 转化率在同行业排 X%」）—— 这是网络效应的起点

## 二、商业化设计

### 定价结构：**席位 + 用量**

席位覆盖 CRM/协作等确定性成本；用量覆盖 AI、线索、发信等变动成本。纯席位制会在重度 AI 用户身上亏钱，纯用量制则收入不可预测。

| 版本 | 价格（人民币） | 包含 | 目标客群 |
|---|---|---|---|
| **Free** | 0 | 1 席位、1 邮箱、200 联系人、基础 CRM | SOHO 引流（PLG） |
| **Starter** | ¥1,980/年·席位 | CRM + 统一收件箱 + 报价 PI + 送达率体检；含 2,000 AI credits/月 | 1–5 人 SOHO/小团队 |
| **Growth** | ¥3,980/年·席位（起订 5 席） | + 线索雷达 + 序列自动化 + WhatsApp + 渠道归因；含 10,000 credits/月·席位 | **5–30 人（首发主打）** |
| **Scale** | ¥6,800/年·席位（起订 20 席） | + 内容工厂 + 站群 + 订单交付 + Agent 平台 + 开放 API | 30–200 人 |
| **Enterprise** | 面议 | 私有化/专属区域、SSO、数据驻留、定制集成、SLA | 大型集团 |

**用量包（超出部分）**：
- AI credits：¥100 / 10,000 credits
- 海关数据查询：¥0.8–2 / 条（随供应商成本浮动，明码标价）
- 发信量：Starter 每席 2,000 封/月，Growth 8,000 封/月，超出 ¥0.05/封
- 站点托管：每站 ¥600/年（含 CDN）

**定价锚点合理性**：市面 SaaS 版外贸 CRM 约 3,000 元/年（10 人）属于极低价位的轻量产品；拓客类工具月付 159 / 年付 1,199（2 子账号）；通用 CRM 每用户每月 $20–300。我们 Growth 版折合每人每月约 ¥332（约 $46），处于国际通用 CRM 中低段、但功能覆盖获客到交付的全链路——**对标价值高、对标价格中**，这是可讲清楚的定价故事。

**关键商业设计**：
1. **AI credits 必须对客户可解释**——界面上明示「这次 AI 写信消耗 3 credits」。不透明的用量计费是 churn 的第一杀手。
2. **不按线索条数卖断**，避免变成低毛利数据贩子；数据是能力的输入，不是产品本身。
3. **年付为主**，外贸客户预算按年，且年付大幅降低 churn。

### 单位经济（Growth 版，10 席位客户的估算模型）

| 项 | 月度 |
|---|---|
| 收入 | ¥3,317（¥3,980×10÷12） |
| LLM 成本 | ¥350–600（多模型路由 + 小模型批处理后） |
| 海关数据成本 | ¥200–400 |
| 发信/基础设施 | ¥150 |
| **毛利率** | **约 70–78%** |
| CAC（内容 + 销售） | ¥8,000–15,000 |
| 回本周期 | 约 4–6 个月 |

毛利率能否守住 70%+，取决于**模型路由与缓存做得多好**——这是技术方案里 LLM Gateway 的商业意义。

## 三、GTM（进入市场）策略

**第一年不做广撒网，做「一个品类 + 一个市场」的样板**。

1. **选一个垂直品类切入**（建议：机械/汽配/五金这类客单价高、决策链长、海关数据丰富的品类）。做深行业模板包，让第一批客户觉得「这是给我们行业做的」。
2. **PLG + SLG 双轮**：
   - PLG：Free 版 + 「免费邮箱体检报告」（输入域名，10 秒出 SPF/DKIM/DMARC 与送达率诊断）——这是极佳的获客钩子，成本近零、痛点极强、直接展示专业度
   - SLG：垂直行业展会、外贸产业带（宁波/义乌/佛山/东莞）线下沙龙
3. **内容自证**：我们自己用 EMS 的内容工厂做 SEO+GEO 获客。做不到就说明产品不行——这是最诚实的产品验证。
4. **服务商渠道**：外贸代运营、建站公司作为分销伙伴（他们已有客户信任，缺工具）。

## 四、风险与应对（商业侧）

| 风险 | 应对 |
|---|---|
| 巨头（阿里/小满）下场做同样的事 | 我们赌的是**平台中立**：不绑定任何 B2B 平台，帮客户建立自有渠道资产。这是平台系产品在战略上不能做的事 |
| 客户对 AI 效果预期过高 | 销售阶段明确「L1 草稿模式默认」，用「节省时间」而非「保证成交」定义价值；提供 30 天效果基线对比 |
| 数据合规事故 | 合规能力产品化（LIA 向导、opt-in 证据链）反而作为卖点；购买网络安全责任险 |
| 交付重、实施成本高 | M0/M1 严格控制在「自助上手 < 30 分钟」；复杂集成交给服务商生态 |
| 同质化价格战 | 护城河在闭环数据与合规工程，二者都不是靠降价能抹平的 |
